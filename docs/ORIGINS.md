# 项目来源

LocalPerks（邻里惠）是在点评类学习项目基础上继续开发的工程实践项目。

- Java 基础业务沿用黑马点评学习项目的业务与包结构，保留原有作者注释。
- 本地起始 Git 仓库的上游地址为 [yachtywen/ShopLink](https://github.com/yachtywen/ShopLink)。本次发布使用整理后的当前工作区源码，没有把旧仓库的本地配置和运行历史一并上传。
- 后续扩展包括前端业务页面、异步订单与故障处理、两级缓存、查询与消息合批、智能客服、知识检索、共享任务调度、模型配额、用户偏好和测试代码。
- Spring、Redis、RocketMQ、Vue、FastAPI 等依赖的版权和许可归原作者所有。
- 公开检索数据集仅通过下载脚本获取，原始数据、下载缓存和向量不随本仓库发布。使用前应核对原始来源的授权条件。

没有把原学习代码、第三方框架或公开数据集声明为独立原创。第三方代码的授权以其原始来源为准。
